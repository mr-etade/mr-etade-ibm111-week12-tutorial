Definitions & the Trivial Solution

Reminder — Definition

A set $\{\vec{v}_1, \ldots, \vec{v}_n\}$ is linearly independent if the only solution to $c_1 \vec{v}_1 + \cdots + c_n \vec{v}_n = \vec{0}$ is the trivial one, $c_1 = \cdots = c_n = 0$. Otherwise, the set is linearly dependent.

B

Testing with the Determinant

Reminder — Method 3

For $n$ vectors in $\mathbb{R}^n$, build a square matrix $A$ with the vectors as columns. Then $\det(A) \ne 0 \Rightarrow$ independent; $\det(A) = 0 \Rightarrow$ dependent. This method only works when the matrix is square.

The Vector Equation & Row Reduction

Reminder — Methods 1 and 2

Method 1: set up $c_1\vec{v}_1 + \cdots + c_n\vec{v}_n = \vec{0}$, equate components to get a system, and solve. Method 2: form a matrix with the vectors as columns and row-reduce. Count pivot columns — one per column means independent.

D

Choosing a Method & Applications

Reminder — Picking the right tool

Before computing, scan for instant patterns (zero vector, parallel pair, more vectors than dimensions). For square cases, the determinant is fastest. For non-square cases, use row reduction. The vector equation always works but takes longest.
